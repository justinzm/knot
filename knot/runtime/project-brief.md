# Project Brief

## Goal

Produce a small content package that demonstrates the Knot loop without binding the repository to a specific industry, platform, or production pipeline.

## Inputs

- A short content request embedded in this brief.
- The project specification in `runtime/project-spec.json`.

## Outputs

- `artifacts/demo/outline.md`: a concise outline for a short educational post.
- `artifacts/demo/post-draft.md`: a publishable draft based on the approved outline.

## Content Request

Create a short educational post that explains why explicit review gates improve content production workflows.

## Style Requirements

- Clear and practical.
- Neutral professional tone.
- Suitable for a general content-operations audience.

## Review Requirements

- Existence gate: expected artifact files are present and non-empty.
- Structure gate: each artifact uses the required headings.
- Business gate: the content clearly explains the workflow value.
- Compliance gate: the content avoids sensitive claims, private data, and platform-specific promises.
